# Surface: 홈 (`/ko`, `/en`)

## Scope and mode

- 사이트 첫 화면. 모드: **Persuade**.
- 2026-10-03 사용자 판단으로 "RISE CREW 여권" 방향을 폐기하고 재추첨, 사용자가 "데모데이 무대"를 선택했다.
- 2026-10-06 사용자 판단: 슬라이드 11장이 같은 틀로 이어져 "카드뉴스처럼 1~11페이지를 내려가는 느낌, 한 사이트 같지 않다." 무대 분위기(어두운 무대, 코발트 조명, 실제 사진, 거대한 숫자)는 유지하고, 구조를 다시 골랐다. 시안 3개(세 단계 레일, 한 줄의 항로, 사진 벽)를 실제로 만들어 비교했고 사용자가 **세 단계 레일**을 선택했다.
- 같은 날 시안 피드백 두 가지를 반영했다. (1) 아래로 스크롤하는데 옆으로 움직이는 Global 가로 넘김은 불편하다 → 세로 방향으로 바꿨다. (2) 글이 멈추지 않고 계속 흘러가면 읽기 불편하다 → Global은 사진과 글을 함께 고정하고, 도시마다 바뀐 뒤 멈춰 있으며, 손을 떼면 가까운 도시에 맞춰진다.

왼쪽 레일의 Campus → Domestic → Global이 스크롤에 따라 로고 그라데이션(라임 → 초록 → 청록 → 파랑)으로 차오르고, Global에 들어서면 화면이 멈춘 채 싱가포르 → 도쿄 → 마카오 → 베트남 사진이 아래에서 위로 한 장씩 덮인다.

## Direction contract

THESIS: 홈은 RISE CREW가 실제로 운영하는 세 단계(Campus → Domestic → Global)를 따라가는 하나의 긴 무대다. 왼쪽 레일이 지금 어느 단계에 있는지 끝까지 붙잡아 주고, 실제 사진과 거대한 숫자가 단계마다 증거를 댄다. 같은 틀의 슬라이드를 반복하는 발표 형식과, 단체 사진 히어로 아래 카드 격자를 늘어놓는 창업 사이트의 정석은 둘 다 거부한다.

OWN-WORLD: 어두운 객석 위 무대. 바탕은 거의 검은 무대색이고, 로고 코발트가 숫자 구간의 조명처럼 사진을 물들인다. 사진은 화면 폭을 꽉 채우거나 크게 놓이고, 아래쪽에 장소·날짜와 "임시" 표시를 단다. 장(章) 제목 Campus · Domestic · Global은 화면을 가로지르는 거대한 디스플레이 글자다. 로고 심볼 그라데이션은 레일의 진행 표시에만 쓴다. 라임은 R·I·S·E 머리글자, 행동 버튼, 일부 숫자에만 쓴다. 로고에 없는 색(남색 등)은 메인으로 쓰지 않는다. 16:9 스크린 틀과 슬라이드 번호는 쓰지 않는다.

STORY: 슬로건과 사람들 사진으로 시작해, 숫자(90+ · 22+ · 33)로 규모를 보여준다. 그다음 Campus(ANCHOR 사업단 공식 동아리, VCC 18회차, 교내 프로그램), Domestic(카카오모빌리티 MOU, 성창재 팀당 500만 원, 멘토 33명), Global(해외 현장 4곳, AI+X 경진대회 5개국 15팀)을 차례로 증명하고, 마지막에 지원하기와 제휴 문의로 끝난다. 기관과 파트너는 Campus·Domestic에서 신뢰하고, 학생은 Global 사진에서 "나도 저기에"를 믿는다.

FIRST VIEWPORT: 워크숍 단체 사진이 화면 전체를 채운다. 왼쪽 아래에 라임 머리글자의 R·I·S·E 슬로건과 국문 한 줄, 오른쪽 아래에 "제휴 문의" 링크와 라임 "지원하기"(모집 기간이 아니면 "모집 안내 보기") 버튼. 스크롤을 시작하면 화면이 멈춘 채 사진이 뒤로 물러나며 어두워진다.

FORM: 데모데이 무대(키노트) 세계 안의 구조 재추첨. 화면 구조 시드 키 616948de에서 세 구조(세 단계 레일, 한 줄의 항로, 사진 벽)를 시안으로 만들어 비교했고, 사용자가 세 단계 레일을 선택했다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

### Signature interaction and motion

- 첫 화면: 사진이 고정된 채 1.18배에서 1배로 물러나고 어두워진다(스크롤 연동).
- 숫자: 코발트로 물든 사진 위에서 90+ · 22+ · 33이 화면에 들어올 때 같은 박자로 카운트업하고, 스크롤에 따라 글자 굵기가 400→950으로 변한다.
- 단계 레일: 세 장(章)에 들어서면 나타난다. 데스크톱은 왼쪽 세로 레일, 휴대폰은 화면 위쪽 막대. 진행 표시는 로고 그라데이션으로 차오르고, 지금 단계에 불이 켜진다(`aria-current`). 각 항목은 해당 장으로 가는 링크다.
- Global 고정 갤러리: 사진과 글을 함께 고정한다. 도시마다 스크롤 한 화면을 쓰고, 그 앞부분에서만 바뀐다(사진은 아래에서 위로 덮고, 이전 글이 빠진 뒤 새 글이 올라온다). 나머지는 멈춰 있어 읽을 수 있다. 근접 스크롤 스냅으로 가까운 도시에 맞춰진다. 움직임 방향은 항상 스크롤 방향과 같다(가로 이동 금지).
- JavaScript가 없거나 `prefers-reduced-motion`이면 확대, 굵기 변화, 카운트업, 고정 갤러리를 끄고 최종 상태를 보여준다. Global은 사진과 설명이 세로로 나열된다.
