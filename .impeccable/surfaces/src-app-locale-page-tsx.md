# Surface: 홈 (`/ko`, `/en`)

## Scope and mode

- 사이트 첫 화면. 모드: **Persuade**.
- 1단계 범위: 정적 데이터, 한국어/영어. 최근 소식, 숫자 자동화는 2단계에서 DB로 교체.

## Audience, action, proof

- 기관·파트너: 실적을 믿고 제휴·후원 문의 → Contact.
- 예비 지원자: 받을 수 있는 것과 지원 자격을 이해하고 → Join.
- 신뢰가 먼저, 행동이 다음 (PRODUCT.md 원칙 2).
- 근거: ANCHOR 사업단 공식 동아리, 카카오모빌리티 MOU(2025.11.28), VCC 18회차, 멘토 33명, 90+ 멤버, 22+ 팀(2026.01 기준), AI+X 글로벌 창업경진대회 공동 주최(5개국 15팀 본선), 해외 활동(베트남 TECHFEST, 싱가포르 SMU, 도쿄 Sushi Tech 2026, 마카오 Beyond Expo 2026), 언론 보도 3건.
- 필수 요소(사용자 확정): 굵은 슬로건, 스크롤 연출, 로고 색(코발트 블루 글자, 라임→청록→하늘→파랑 심볼 그라데이션)이 메인 색.

## Direction contract

THESIS: 동아리를 "캠퍼스에서 세계로 도장이 찍혀가는 여권 한 권"으로 보여준다. 어두운 단체 사진 위 두 줄 슬로건과 카드 격자로 이루어진 창업 동아리 사이트의 정석 배치는 거부한다.

OWN-WORLD: 첫 화면은 로고 코발트 블루로 칠한 여권 표지(엠보싱된 R 엠블럼). 속지는 옅은 청록 보안 용지 위에 로고 심볼의 라임→청록→하늘→파랑 그라데이션으로 인쇄한 길로셰 무늬. 라임 그린은 Global 단계와 강조에 쓴다. 로고에 없는 색(남색 등)은 메인으로 쓰지 않는다. 정보는 여권 신원 면 문법(한글/영문 짝 라벨, 필드 칸, 하단 MRZ 판독 줄)으로 놓는다. 성과는 날짜와 장소가 찍힌 잉크 도장, 예정 일정은 빈 점선 도장 칸. 지원하기는 절취선이 있는 탑승권.

STORY: 기관과 파트너는 표지와 신원 면의 근거(사업단, MOU, 숫자)로 신뢰하고, 학생은 도장이 쌓이는 경로를 보며 "나도 여기서 출국할 수 있다"고 믿는다. 끝에서 탑승권(지원)과 제휴 문의 중 하나를 누른다.

FIRST VIEWPORT: 화면 전체가 코발트 블루 여권 표지. 위쪽에 작게 "성균관대학교 · SKKU", 가운데 R 엠블럼, 그 아래 R·I·S·E 머리글자를 강조한 슬로건이 화면 폭을 채우는 크기로. 아래쪽에 신원 면이 살짝 겹쳐 올라와 90+ 멤버 · 22+ 팀 · 멘토 33명이 보인다. 오른쪽 아래에 탑승권 모양의 "지원하기"가 기본 행동, 그 옆에 "제휴 문의"가 보조 행동.

FORM: 여권과 출입국 도장, 보안 인쇄. 내 후보 목록 7개 중 5번째. 시드 키 82fe2e10.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

### Raises (declined challengers)

- 크랙트로 스크롤러: 글을 읽는 동안 글자 면은 멈춰 있고, 배경 길로셰만 스크롤 깊이에 따라 움직인다.
- 7세그먼트 디스플레이: 아직 열리지 않은 일정은 빈 점선 도장 칸으로 그려, 비어 있음까지 디자인한다.
- 행사 부스 카탈로그: 창업팀 목록은 여권번호 같은 코드를 단 촘촘한 칸 격자로 만들고, 도장과 지도 위치를 서로 잇는다.
- 90년대 CD-ROM 콘솔: 지원하기 버튼은 도장을 찍듯 실제로 눌리는 깊이를 가진다.
- 자카드 직조: 모든 도장은 근거(기사, 사진, 날짜)로 이어져, 누르면 출처가 열린다.
- 텐세그리티 기둥: 모든 숫자 옆에 기준을 단다 (예: 90+ 멤버 · 2026.01 기준).

### Signature interaction and motion

- 스크롤 진행에 따라 길로셰 색상이 파랑(Campus) → 초록(Global)으로 이동한다. CSS 스크롤 기반 애니메이션을 쓰고, 지원하지 않는 브라우저에서는 정적 그라데이션으로 대체한다.
- 도장은 화면에 들어올 때 한 번만 찍힌다(짧은 ease-out, 살짝 눌렸다 놓이는 느낌). 스크롤을 가로채지 않는다.
- `prefers-reduced-motion`이면 도장은 바로 표시되고, 색 이동은 섹션 단위 정적 색으로 바뀐다.
